## Technical findings

`StartDoubleWildBattle` in src/battle_setup.c uses CB2_EndWildBattle and only sets BATTLE_TYPE_DOUBLE. `StartScriptedWildBattle` supplies the script-return callback but sets BATTLE_TYPE_WILD_SCRIPTED without DOUBLE. PR7 is merged (merge55665c6d876a1be5d2d8afecf8d0c47300048b42), so the old register's unmerged-prototype note is historical. No production scripted-two-object producer currently joins these contracts. docs/WILD_DOUBLE_BATTLES.md records real survivor capture and rejects balls with both opponents alive; capturing the survivor ends the encounter. This supports permitted KO/capture outcomes, not two captures. SOW005 must supply focused positive/negative tests for both object entry points and joint cleanup before acceptance.

Noctowl's src/data/pokemon/tmhm_learnsets.h row includes HM02_FLY. src/party_menu.c retains the badge-by-field-move check and Fly setup restrictions. This is source compatibility, not an executed Fly UI/field acceptance claim; no HM gate change is proposed.

The original static removeobject command sets the object's hide flag. Original birds separate the hide flag from the successful encounter flag and clear temporary hiding on unresolved reentry. Heracross follows this pattern with separate4AD/4AE flags; other new statics must preserve the same outcome distinction. Never share one success/hide flag for fled-object removal.

No unsupported Route14 Absol, Route17 Donphan, Seafoam Sneasel, Route21 Sealeo or alternate Noctowl species are introduced. Species/location/story/weather choices are closed; deferred combat details and real implementation gates remain distinct.
